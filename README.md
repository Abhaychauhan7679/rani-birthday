# Rani Birthday Website 💗

Birthday: 20 August 2026

## Files
- index.html — animated home + countdown
- story.html — birthday story
- memories.html — photo gallery
- letter.html — birthday letter
- surprise.html — final surprise
- style.css — pink theme, responsive layout, animations
- script.js — countdown, floating hearts, reveal animations and music button
- assets/ — uploaded photos

## Run
Open `index.html` in a browser.

## GitHub Pages
Upload the complete folder contents to a GitHub repository, then enable:
Settings → Pages → Deploy from a branch → main → / (root)
